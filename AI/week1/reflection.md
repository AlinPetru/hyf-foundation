# hyf-foundation


1. Identify and share 3 new things you learned from AI in the above task.

I learned how to structure a webpage using HTML, CSS, and JavaScript together.
I learned that JavaScript can make a webpage interactive and behave more like a game.
I learned that AI can help generate a starting point for a project, which I can then modify and improve myself.

2. Where did you have to tweak or correct Copilot’s suggestions to suit your needs?

I had to adjust some of Copilot’s suggestions because they did not exactly match the design and functionality I wanted. I also needed to correct parts of the code when the result was different from what I expected. This helped me understand that AI-generated code still needs to be checked and tested.

3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

Using Copilot to generate code means letting it do most of the work without necessarily understanding how the code works. Using it as a learning partner means asking questions, requesting explanations, and using its suggestions to understand the concepts yourself. The second approach helps me develop my own problem-solving and programming skills.

4. Identify 3 risks of relying too much on AI tools when learning at HackYourFuture.

One risk is becoming dependent on AI and struggling to solve problems without it. Another is copying code without understanding what it does, which can create gaps in my knowledge. A third risk is accepting incorrect or inefficient AI suggestions without checking them, which could lead to bad programming habits.
